JPEG XL could not be verified

VulkanScope Database needs a browser or compatible extension capable of displaying JPEG XL images. An image download or server MIME error can also prevent verification; this is not always a missing decoder.

What to do

Check your connection and verify the browser can display JPEG XL. Supported engines, extensions, and browser distributions differ; the site tests actual image rendering, not a browser allow-list.

For Edge on PC: if the package contains manifest.json, extract it, open edge://extensions, enable Developer mode, then choose Load unpacked and select that folder. Android installation is browser-build-specific and cannot use the desktop Load unpacked procedure. Review package permissions and reload this site.
