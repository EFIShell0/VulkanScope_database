# VulkanScope Database 1.3.6 report-detail evidence workspace / Raw-report download audit

Database 1.3.6 is a presentation/export-only successor to immutable Database 1.3.5 (`92c86c9013f4bab4ea8376e5db07c965b035843313c893561b047957e5189e97`). D1 schema/migrations, stored payload bytes/hashes, report IDs, normalizer 16, Vulkan 1.4.362/header 362, VulkanScope 1.2.5 submission floor and browser floors are unchanged.

Mandatory checks:

- Overview keeps its established metadata grouping. Every other visible report-detail tab is rendered through the new evidence-workspace language: section intro, bounded summary statistics where meaningful, evidence panels, explicit empty states and the existing state badges/table controls.
- Registry, Properties, Limits, Features, Formats, Memory, Queues, Surface, Display & HDR, Extensions, Instance, Profiles and Raw report remain independently navigable; category emptiness never removes the tab.
- Canonical Vulkan tokens, exact raw masks/values, query availability, support/availability semantics and not-reported/Unknown boundaries are unchanged. The redesign is presentation-only.
- Raw report explains that `reportText` is preserved independently from structured/normalized evidence. Download uses only `r.reportText`, produces a UTF-8 `text/plain` Blob without adding a newline or reformatting, triggers a local object-URL download and adds no Worker/export endpoint or D1 mutation.
- Raw report uses `.raw-report-scroll` in the shared `SURFACE_SCROLL_SELECTOR`, so the first-party surface-scrollbar rail replaces native chrome only when real overflow exists. Pointer, keyboard, wheel/touch and reduced-motion behavior are inherited from the shared scrollbar system.
- New report-detail CSS is scoped to detail workspace classes, contains desktop/mobile containment, and keeps intentional table-local scrolling. `prefers-reduced-motion` suppresses decorative transitions.
- Existing 1.3.5 Submitted time-zone wrapping, 1.3.4 demand-driven filter scrollbar, Compare chevrons, 1.3.3 motion and release-convergence contracts remain intact.
- Browser-visible identity advances to 1.3.6 / cache key 1306; Pages keeps only the 1.3.5 frontend triplet as the immediate propagation bridge.
- Focused verifier, negative mutation suite, immutable predecessor contract, full source/Pages audits, Worker contract, D1 replay and deterministic clean-extract package verification are release-blocking.
- No D1 migration is required for 1.3.6.
