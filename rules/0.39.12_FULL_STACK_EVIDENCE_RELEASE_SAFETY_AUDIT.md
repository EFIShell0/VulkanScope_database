# VulkanScope Database 0.39.12 full-stack evidence / release-safety audit

## Scope

- Audited frontend normalization, aggregate/detail/Compare state semantics, exact-width Vulkan values, Worker validation/read normalization, legacy TXT import, published JSON Schema, repository checks and staged Pages output.
- Producer/query compatibility remains VulkanScope 0.41.13 / 423, Vulkan 1.4.360, schema 2 / technicalReport 3 and compatible producer floor 0.32.4+.

## Corrections

- Structured schema-v3 collections now replace stale TXT fallback feature/property/limit rows and Worker normalizer 17 exposes structured memory, format, extension, layer, Surface, profile, Display/HDR and registry data on read.
- Compare no longer reclassifies generic false Surface properties as Unsupported. Report detail distinguishes missing Display/HDR evidence from explicit Unavailable evidence.
- Exact U64 memory byte strings remain visible, raw-report search duplication is removed and bounded report dispatch avoids quadratic queue shifting.
- TXT import preserves generic false/zero values as Available and keeps feature booleans Supported/Unsupported.
- Worker rejects invalid UTF-8, impossible security-patch dates, empty required identity strings and structured raw-version objects. `report.schema.json` now describes the same required envelope.
- Pages staging cannot replace an arbitrary existing directory and deploys only allow-listed `data/index.json`; unexpected artifact JSON fails audit.

## Release invariants

- `app.v03912.js` and `config.js?v=03912` provide cache busting; `site.v0390.css` is unchanged.
- Worker compatibility date stays 2026-08-23. D1 schema/data, report IDs, canonical submission hashes and stored payloads are unchanged.
