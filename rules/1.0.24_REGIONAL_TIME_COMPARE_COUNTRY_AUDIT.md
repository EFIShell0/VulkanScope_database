# VulkanScope Database 1.0.24 regional time / Compare / country audit

## Scope
1.0.24 is a frontend presentation and interaction release over immutable 1.0.23. It does not change D1 schema/migrations, stored report bytes/hashes, submission validation, Vulkan normalization, or producer compatibility.

## Connectivity
- Removed the redundant `UNAVAILABLE` chip from the right edge of the Database-unavailable banner while retaining the explanatory banner itself.
- Recovery state is now sticky for its complete 3000 ms success interval. Further successful probes during that interval do not prematurely switch the banner to hidden online state.

## Regional date/time preferences
- Added bounded Settings controls for region, date order, clock mode, time zone and seasonal offset.
- Automatic time-zone mode uses the browser zone. UTC/GMT and browser-supported IANA zones are selectable.
- Automatic seasonal mode follows IANA rules; standard/winter and daylight/summer modes apply a display-only current-year offset override.
- One formatter pipeline is used for report-list submission dates, report detail, Compare report identity, Settings clock and observed server time. Raw timestamps and sort/filter instants are unchanged.
- Persistence stays opt-in under Remember on this device and is limited to the explicit preference allow-list.

## Country identity
- `/v1/network-info` remains request-scoped/no-store and unchanged at the D1 boundary.
- Two-letter request country codes are expanded with `Intl.DisplayNames` and rendered with the corresponding ISO regional-indicator flag glyph. No third-party flag service or runtime request was added.

## Compare workspace
- Added baseline/candidate A/B cards with report metadata, swap action, grouped comparison-mode controls, dedicated evidence filtering, summary emphasis, section counts and differentiated A/B table columns.
- Existing canonical compare evidence generation, technical-difference filtering, common-evidence filtering, cross-producer warnings and profile-revision warnings are preserved.

## Release gates
The 1.0.24 verifier and negative mutations cover recovery timing, no-unavailable-chip behavior, regional preference validation/persistence, centralized timestamp formatting, country expansion/flags and Compare workspace controls. Existing source/Worker/D1/Pages/regression/deterministic-package gates remain mandatory.
