# VulkanScope Database 1.0.15 Versions / motion / loading / overlay audit

## Release identity
- Database version: 1.0.15
- Immutable predecessor: VulkanScope Database 1.0.14
- Producer/query baseline remains VulkanScope 1.0.19 / Vulkan 1.4.362.
- Submission schema 2, technical report 3, normalizer 16 and D1 storage schema remain unchanged.

## Requested changes
- Adds the previously omitted fixed-left three-line disclosure controls to Reports Vendor and Type; both expand only to the right like Submitted and retain horizontal table growth.
- Versions now presents per-version shares as circular ring statistics. A separate table below lists exact report counts and plain percentage text; Versions no longer calls the shared coverage-bar renderer.
- Global, Encyclopedia and row-filter searches use the same animated local clear-X control. Browser-native search cancel glyphs are suppressed to avoid inconsistent abrupt behavior.
- Buttons, links, cards, selectors and search surfaces share short soft hover/press/focus transitions with a reduced-motion fallback.
- Route/filter/search renders pulse a small loading line across the major box families, including metrics, cards, section panels, tables and key/value boxes.
- Windows CI repairs history-bearing checkout overlays before canonical-state verification. This directly handles stale `assets/app.v1013.js` / earlier app assets left by extracting a newer source ZIP over an existing Git working tree. The repair is followed immediately by strict `--check`.

## Preserved 1.0.14 contracts
Pinned Submitted disclosure, complete multi-state coverage dominance/hatching, zero-state empty hatching, Developer Info, raw vendor-ID provenance, modal Coverage reports, high-percentage endpoint glow, exact HDR10+ artwork and resolution/gamut chip typography remain mandatory and are rechecked by the 1.0.15 verifier.
