# VulkanScope Database 0.33.5 UI and parity audit

- Replaced browser-native visible filter option UI with a progressively enhanced local custom listbox while retaining native select state.
- Replaced visible navigation scrollbar with dedicated left/right scroll buttons, edge fades, touch/trackpad scrolling and vertical-wheel-to-horizontal support.
- Added the official VulkanScope repository action to the hero heading row.
- Re-audited the current Vulkan Hardware Database frontend categories: Core 1.0-1.4 properties/features, extension properties/features, linear/optimal/buffer formats, memory, queue families, surface formats/present modes/transforms/composite alpha/usage, instance data, portability and profiles remain represented.
- Expanded Compare to include device metadata, normalized capabilities, device/instance extensions, formats, queue families, memory heaps/types, Surface/WSI and Profiles instead of only generic capabilities.
- State semantics and canonical/raw Vulkan value rules remain unchanged.
