# VulkanScope Database 1.3.2 cache / pointer / pagination UI audit

- Release identity: **1.3.2**; immutable predecessor: **1.3.1**, SHA-256 `ec60e0456f46427713db697e6bd0b8e7742dfad62843e9743befdc3576da84dc`.
- Refresh root cause: 1.3.1 could reveal a stale document after a single startup publication check while GitHub Pages/CDN edge objects (release marker, index and versioned runtime assets) were still converging. A later ready release could therefore require a manual refresh/prompt.
- Freshness correction: 1.3.2 keeps first paint bounded, continues no-store publication checks after reveal, retries during the early convergence window and on visibility/pageshow/online lifecycle events, validates the marker + index + app + compatibility gate + bootstrap as one publication generation, and automatically replaces the document only after the complete generation is proven ready.
- Deployment compatibility: immutable 1.3.1 app/browser-compat/bootstrap assets are retained for one transition release so a stale 1.3.1 HTML edge never references files removed by the 1.3.2 artifact. No predecessor bytes are rewritten.
- Pointer correction: blank custom-scrollbar rail/gutter pixels have `pointer-events:none`; only arrow/track/thumb controls accept input. Custom-select internal click/drag-release events are excluded from the document outside-click closer.
- Pagination correction: filter Previous/Next controls use fixed compact icon cells, the page-jump occupies the flexible middle cell, and mobile/global pager constraints cannot force horizontal overflow.
- Independence notice: exact English text is unchanged but presented as a modern blue information card with an `i` icon in Settings and the footer.
- Browser information presentation is otherwise unchanged from 1.3.1. No browser-logo bundle is added by this release.
- Semantic invariants: D1 schema and migrations, payload bytes and hashes, report IDs, normalizer 16, Vulkan 1.4.362/header 362, browser floors and VulkanScope 1.2.5 submission floor are unchanged.
- Mandatory gates: focused 1.3.2 verifier + negative mutations, predecessor hash contract, source/Pages audit, JS/Python syntax, route/compare/text tests, Worker contract, D1 migration replay and deterministic strict-package verification.
