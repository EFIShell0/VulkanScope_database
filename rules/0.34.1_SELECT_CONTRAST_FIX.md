# VulkanScope Database 0.34.1 custom-select contrast fix

- System Vulkan driver choices render only the reported GPU model in strong white text.
- The `— System Vulkan driver <version>` suffix remains normal-weight muted text, including selected/hovered rows.
- Turnip / third-party choices retain the existing red-accent treatment.
- Native `<select>` values remain authoritative; this change is presentation-only.
- The fix uses explicit CSS color/weight rather than inherited option color so custom-listbox state styles cannot erase GPU emphasis.
