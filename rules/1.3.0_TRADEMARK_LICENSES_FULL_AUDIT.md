## Vulkan® presentation contract

Standalone user-facing `Vulkan` is presented as `Vulkan®`. `VulkanScope` is never rewritten. This is deliberately a presentation layer only: canonical/raw evidence, report JSON, API/schema/token values, registry text, URLs, filenames, source identifiers and persisted values retain their canonical bytes. Static HTML is release-authored with the mark; runtime-rendered labels, text, titles, placeholders and ARIA labels pass through an idempotent DOM presentation observer. Raw/canonical regions (`pre`, `code`, scripts/styles, textareas, `.raw`, and the explicit preservation attribute) are excluded.

## Information and license reading

The Information inventory distinguishes browser runtime code, deployment/toolchain components, managed services and platform APIs. Exact versions are shown only where this repository pins them. Wrangler is pinned directly, sharp is pinned by override, while esbuild/workerd are identified as Wrangler-resolved components rather than being assigned fabricated transitive versions without a committed lockfile.

Same-origin Markdown license/notices are bundled for the applicable software components:

- `licenses/wrangler.md` — Cloudflare Workers SDK/Wrangler, MIT OR Apache-2.0 upstream terms.
- `licenses/sharp.md` — sharp, Apache-2.0 upstream terms.
- `licenses/esbuild.md` — esbuild, MIT upstream terms.
- `licenses/workerd.md` — workerd, Apache-2.0 upstream terms.
- `licenses/nodejs.md` — Node.js license plus bundled third-party notices from the official distribution license text.
- `licenses/python.md` — Python/CPython official license text.

Each applicable Information card provides a same-origin **Read license (.md)** link opened with `noopener noreferrer`. No remote JavaScript, analytics, advertising code, remote font or license-viewer dependency is added. Cloudflare D1 and Web Platform APIs remain described as services/APIs, not falsely presented as bundled libraries with software-license buttons.
