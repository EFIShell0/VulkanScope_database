# VulkanScope Database 0.35.9 Display & HDR / ABI / home parity audit

## Scope
- Rename Display / HDR presentation to Display & HDR in primary navigation, metadata, report detail and comparison labels.
- Show producer-reported supported device ABIs beneath the application ABI in Reports.
- Render numeric Android HDR luminance evidence with cd/m² in aggregate and report-detail views.
- Add separate Producer/query baseline and Compatible producers home metrics.

## Evidence semantics
These are presentation and compatibility-visibility changes only. Raw Vulkan report evidence, schema-v3 structured data, supported/unsupported/available/unavailable/unknown semantics, and stored D1 payloads are not rewritten.

## Security and usability
No new third-party resources, remote scripts, fonts, analytics, storage writes, or network origins are introduced. ABI arrays remain escaped before HTML insertion. Luminance text is escaped after unit normalization.
