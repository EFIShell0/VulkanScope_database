## Report startup architecture
The old browser loader paged the complete report index and then blocked on a compact API GET for every report on every page visit. 1.0.3 replaces that startup path with a deploy-time snapshot:

1. `tools/build_preload_snapshot.py` reads the complete paginated Worker index.
2. It fetches every compact report with bounded concurrency during deployment, not during each reader visit.
3. It emits a small manifest plus content-hashed JSON chunks capped below the browser 4 MiB response ceiling.
4. The browser loads the same-origin snapshot first, normalizes it with the existing frontend normalizer, and can render immediately once that snapshot is complete.
5. The browser then refreshes the live index asynchronously and fetches only missing report IDs; a successful live refresh also prunes IDs no longer present in the authoritative index.
6. A requested report/Compare route absent from the deploy snapshot is fetched directly before route application rather than forcing a full-database blocking refresh.
7. If the static snapshot is missing or invalid, the existing bounded live loader remains the fail-safe path.

This preserves the rule that aggregates are computed only from reports actually loaded into the frontend while removing the repeated N-report startup wait from normal deployed visits.

## Scroll UI
- A fixed 3 px reading-progress bar at the top scales from 0 to 1 using the real page scroll range and reverses smoothly when scrolling upward.
- Up/Down controls no longer switch with `button[hidden]{display:none}`. Boundary eligibility is class-driven and opacity/transform/visibility transitions provide a smooth appearance/disappearance.
- The top/middle/bottom button eligibility contract is retained.
- Eligible controls become visible during scroll activity and fade after 900 ms of inactivity.
- `prefers-reduced-motion` removes decorative transitions while retaining state and navigation behavior.

## Filter icon semantics
The custom listbox renderer retains the native `<select>` as the authoritative control and now maps filter dimensions to local inline SVG concepts: loader/API layers, driver, extension, physical-device type, Android/device, ABI/code, VulkanScope application version, date, HDR, gamut, resolution, refresh and display mode in addition to existing vendor/GPU/state/order icons.
