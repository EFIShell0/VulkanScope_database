# VulkanScope Database 1.0.25 audit

Scope: connectivity responsiveness, Settings Internet live observations, local country-flag rendering, scroll/select visual consistency, and presentation-only redesigns of Surface and Encyclopedia.

## Invariants

- 1.0.24 is the immutable predecessor (`d2cfde68221dbab5ceb461e14e4afcef1171de4747798a264d4db7ca2a575e27`).
- No D1 migration, report-payload rewrite, report hash change, schema bump, normalizer change, registry change, Vulkan evidence inference or producer-floor change is introduced.
- Offline is event-first; API reachability is probe-backed and the first failed live probe may surface unavailable state.
- Restored state remains visible for five seconds and has no redundant right-side Online badge.
- Internet observations auto-refresh only while the Internet Settings panel is relevant and use no persistent storage.
- Country flag artwork is bundled same-origin and keyed only by validated country code. No runtime third-party flag request exists.
- Native selects remain authoritative; custom dropdown UI and scrollbars are presentation/accessibility layers only.
- Surface and Encyclopedia redesigns do not alter report/reference data semantics.
