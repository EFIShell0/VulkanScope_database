# VulkanScope Database 0.35.4 Cloudflare account isolation

The Worker configuration is pinned to the established VulkanScope Cloudflare account and production D1 UUID. The `vulkanscope` Wrangler auth profile can be bound to this project's worker directory so VulkanScope and other projects can use separate Cloudflare accounts without repeated logout/login cycles.

Production npm operations verify the active Cloudflare account before invoking Wrangler. A missing, unreadable or mismatched account blocks the operation. The root `.gitignore` excludes local authentication/environment state, dependencies, logs and build caches. No report schema or D1 migration changes are part of this release.
