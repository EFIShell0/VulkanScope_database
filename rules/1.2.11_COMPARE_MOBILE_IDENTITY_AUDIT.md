# VulkanScope Database 1.2.11 — Compare mobile identity audit

## Reproduction
On narrow/mobile Compare cards, `compareIdentityMarkup()` emits GPU, vendor and driver as three flex items. The historical `.compare-identity-line{max-height:40px}` normal-state transition cap can be exceeded after wrapping. The following `.compare-identity-meta` chip row then paints into the same vertical area, which is visible as `System Vulkan driver …` overlapping the Baseline/Candidate chips.

## Correction
- Keep the existing compact-state collapse at `max-height:0`.
- Raise the full-state animation ceiling to a non-clipping value (`20rem`) so content owns the card height instead of colliding with the chip row.
- At <=760 px, lay out GPU, vendor and driver identity rows in one intrinsic column and permit safe wrapping with no technical-value rewrite or ellipsis.
- Keep metadata chips in their existing independent wrapping row below the identity block.
