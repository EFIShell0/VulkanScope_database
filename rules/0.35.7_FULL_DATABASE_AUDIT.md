# VulkanScope Database 0.35.7 full database audit

Base: VulkanScope Database 0.35.6. Producer: VulkanScope 0.33.7.

Audit areas: current producer contract, schema-v3/TXT parity, Vulkan specification provenance, property/feature/limit/format coverage semantics, Display/HDR state semantics, frontend network containment, Worker schema/privacy/security, Cloudflare/D1 deployment pins, accessibility and cache-safe deployment.

## Fixed
- Missing property/limit/feature rows now contribute Unknown across the loaded-report denominator.
- Missing format rows now contribute Unknown rather than disappearing.
- Display/HDR uses explicit producer state and distinguishes missing evidence (Unknown) from explicit empty HDR enumeration (Unavailable).
- Frontend reads are timeout/size bounded, repeated pagination cursors fail closed, and detail fetch concurrency is reduced to four.
- New submissions cross-check schema-v3 primary-device data against top-level index fields and validate current VulkanScope TXT report identity/sections.
- API responses add CORP/COOP and restrictive CSP headers.
- Public specification provenance updated to Vulkan 1.4.359 (2026-08-07); producer/query staging baseline remains 1.4.360.

## Unchanged
D1 schema, report IDs/deduplication model, stored payloads, canonical Vulkan token preservation, exact U64 handling, request-IP non-persistence, Cloudflare account/D1 pins, Vulkan-red branding and 0.35.3 coverage-dominance styling.
