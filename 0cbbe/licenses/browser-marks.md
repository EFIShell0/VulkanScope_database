# Browser identification marks

VulkanScope Database uses browser marks only to truthfully identify a browser that the browser itself exposes to the local Settings > Internet > Browser information view. The marks are bundled same-origin; the UI never contacts a logo CDN, brand service, analytics endpoint, or fingerprinting service to obtain them.
