- D1 migration: none

## Requested presentation repairs
- Low coverage remains numerically exact but no longer deforms into wedges or angled end shapes. Values below 20% use only a thick black diagonal hatch over the semantic state color; values below 5% use the same non-deforming hatch contract.
- High coverage at 80% and above adds a bounded highlight/glow treatment. The animation is decorative only and becomes static under `prefers-reduced-motion`; state colors and percentages remain authoritative.
- Reports submission Date / Time / Time zone remain derived from server-authored `submitted_at`, but the metadata body is collapsed by default to avoid forcing the wide timestamp block into every row. A three-line button in the Submitted header expands/collapses those three lines without changing sorting or stored data.
- Expanded timestamp presentation provides sufficient width/wrapping for the browser-local time-zone label instead of allowing it to collide with the Device column.
- Opening a report stores the exact scroll position of the source route. Browser Back and the in-page Back control restore the source route to that stored vertical position instead of returning to the top. Report detail opens at the top. History scroll restoration is controlled explicitly so native restoration does not fight the route state.
- The Android-version filter uses the exact current VulkanScope application `ic_android.xml` head artwork geometry and colors as a local inline SVG. No remote asset, script, font, analytics or additional request is introduced.
