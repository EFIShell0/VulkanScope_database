# VulkanScope Database 1.3.10 country-selector search / pagination audit

Database 1.3.10 is a presentation-only successor to immutable 1.3.9. It repairs the Settings Country / region menu so its complete option set is searchable and deterministically paged instead of opening on the selected country's later page with no visible search/pagination controls. No D1 migration, report rewrite, timestamp rewrite, hash change, normalizer change, browser-floor change or Vulkan evidence-semantic change is introduced.

## Root cause and correction

- The shared custom-select implementation already had 50-option pagination, direct page jump and search, but searchability was limited to selectors inside `#contentView` / `#detailView`. The Settings Country / region selector lives outside those containers, so its pager was hidden.
- Opening every custom selector also called `ensureSelected`, which moved the option page to the selected value. With Türkiye selected, the Country / region menu therefore opened on a later page whose first visible entry was around Solomon Islands while the hidden pager prevented access to earlier pages.
- `settingsRegionalCountry` and `settingsRegionalTimeZone` are now explicit searchable large selectors. Their search and pager UI uses the existing shared, accessible custom-select infrastructure rather than a second pagination implementation.
- These Settings large selectors begin an opened browse session at page 1 while the closed control continues to show the authoritative selected value. Other searchable selectors retain their existing selected-page behavior.

## Country selector contract

- Search is applied to the full native option list before pagination, with 50 options per page.
- Search input resets to page 1. Previous, Next, direct page number and Go remain the authoritative pagination controls and retain the established disabled behavior when only one page exists or a jump cannot change state.
- Country options remain English-display-name sorted through `Intl.DisplayNames` plus `naturalCollator`; the two-letter code remains part of the option text and is searchable.
- Opening the menu does not change the native selected country. Only an explicit option selection changes the value and dispatches the existing change path.
- Country mode still enables only Country / region; Manual still locks Country / region to Browser / system. Country-profile date/time-zone information and server timestamp semantics are unchanged.

## Release identity

Current cache identity: app/browser-compat/release-bootstrap `v1310`, stylesheet `site.v1309.css`, cache key `1310`; the immutable 1.3.9 JavaScript triplet is the immediate startup/cache bridge.
