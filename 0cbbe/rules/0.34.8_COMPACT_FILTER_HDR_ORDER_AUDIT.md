# VulkanScope Database 0.34.8 audit

- Top-level and secondary filter/sort controls were reduced from the previous large flexible presentation to compact responsive selectors.
- Mobile uses a two-column filter grid when space allows and a single column on very narrow screens.
- Each enhanced selector button and option receives a local inline SVG icon chosen from the selector semantic; no remote icon/font dependency was added.
- Native select elements remain authoritative and existing listbox keyboard behavior is preserved.
- Display/HDR exposes only meaningful state and submission-order controls; Vendor/GPU/Vulkan filters remain hidden and ignored.
- Display ordering uses D1/server `submittedAt` timestamps already present on normalized reports. Missing/invalid timestamps sort as zero and report ID provides deterministic tie-breaking.
