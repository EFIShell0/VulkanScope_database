# VulkanScope Database 1.4.9 — profile / time / loader / startup audit

Database 1.4.9 succeeds immutable Database 1.4.8 (ZIP SHA-256 `ea6233a92cc5ec95951caef9d17eb11c0bdeb6c7a2794637b8ab07fd66af911e`). This release is frontend/startup presentation and loading-path work; it does not alter D1 schema, canonical report identity, stored payloads/hashes, normalizer 16, the VulkanScope 2.0.6+ new-submission floor, or Vulkan 1.4.364 evidence semantics.

## Profiles
Structured VulkanScope 2.0.6 `profileEvaluation` objects are retained instead of being reduced to four fields. Report detail renders mapped/met/unmet/unknown counters, check-family breakdowns, minimum API and evaluator coverage plus reported missing/unknown/failing evidence. Historical reports without those fields remain readable and explicitly omit unavailable detail rather than manufacturing zero counts.

## Regional date/time
Automatic, Country and Manual previews all expose the active zone/locale, current UTC offset, standard/winter and daylight/summer offsets, seasonal-change state and active seasonal policy. Geometry changes use measured-height Web Animations and are disabled by reduced-motion preference without hiding information.

## Current database loading
The deploy-time static snapshot is retained as same-origin cache/fallback data. Startup launches snapshot and live-index reads together; the live index is authoritative, cached bodies seed matching report IDs, and only missing bodies are loaded. Open pages continue to use `/v1/sync` plus compact per-report reads for new submissions, avoiding an unnecessary GitHub Pages rebuild for every POST.

## Startup presentation / scroll chrome
The loader reuses the bundled application logo with local halo, breathing and accent-line/dot motion and scales within desktop/mobile viewport bounds. Page Up/Down controls are offset left of the fixed scrollbar rail with a visible gap on both desktop and mobile.

## Release boundary
Current browser assets are v1409/cache 1409; the v1408 JavaScript triplet is the one-release bridge. D1 migrations remain unchanged. Worker source identity advances to 1.4.9 while producer admission remains VulkanScope 2.0.6+.
