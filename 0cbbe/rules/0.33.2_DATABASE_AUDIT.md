# VulkanScope Database 0.33.3 audit

- Navigation: persistent horizontally scrollable tab strip; deliberate brand gap; mobile/portrait two-row layout.
- Canonical mask audit expanded from memory to VkQueueFlags, VkVideoCodecOperationFlagsKHR, VkFormatFeatureFlags2, VkImageUsageFlags, VkSurfaceTransformFlagsKHR and VkCompositeAlphaFlagsKHR. Raw masks remain visible and unknown bits are retained.
- Formats: canonical decoder follows current Vulkan VkFormatFeatureFlagBits2 values; this also avoids relying on application-side presentation helpers.
- Precision: schema-v3 JSON numeric 64-bit format masks can exceed JavaScript Number safe integer width, so exact TXT decimal masks are retained when available.
- CapsViewer parity checked against current vulkan.gpuinfo.org navigation/list categories: devices, reports, extensions, versions, properties core 1.0-1.4/extensions, features core 1.0-1.4/extensions, formats linear/optimal/buffer, memory, surface formats/present modes/usage/transforms/composite alpha, instance extensions/layers and profiles.

- Additional typed-property canonicalization: subgroup stages/operations, sample-count masks and depth/stencil resolve-mode masks. Unmapped numeric extension properties remain raw rather than being guessed.
