# VulkanScope Database 1.3.9 regional / filter layout profile audit

Database 1.3.9 is a presentation-only successor to immutable 1.3.8. It fixes regional-control containment, changes Manual mode so Country / region is locked to browser/system, expands Country mode with a readable per-country presentation profile, and makes custom-filter scrollbar gutter reservation demand-driven. No D1 migration, report rewrite, timestamp rewrite, hash change or Vulkan evidence-semantic change is introduced.

## Regional mode contract

- Automatic keeps Country / region, Date format, Clock format, Time zone and Seasonal offset disabled and derives display from browser/system Intl state.
- Country enables only Country / region. The selected country drives a representative locale, date order, 12/24-hour convention, representative IANA time zone, current UTC offset and current-year seasonal offset information.
- Manual keeps Country / region disabled and resets it to Browser / system region when Manual is entered. Manual enables Date format, Clock format, Time zone and Seasonal offset only.
- The 1.3.8 wording that Manual unlocks Country is superseded by this release.
- Country information is presentation guidance. Countries with multiple zones use the project representative primary IANA zone and this never changes the server-authored `submitted_at` instant, sorting epoch, age filtering, report identity or Compare identity.
- The country profile displays Date format, Clock format, Representative IANA zone, Current UTC offset, Standard / winter offset, Daylight / summer offset, Seasonal clock change and Current offset state as separate rows. Locale/date/clock conventions and current zone rules are derived with browser Intl APIs rather than fabricated per-country fixed text.

## Custom-select layout contract

- Regional custom selects use the full settings-card width so normal labels such as `Automatic (browser / system)` do not collapse into narrow word fragments.
- Filter/select option labels remain complete and may wrap vertically; they are not hidden behind the scrollbar rail or clipped merely to fit one line.
- The custom-select scroll host reserves right-side rail space only when JavaScript detects real overflow and applies `.has-surface-scrollbar`. A short filter with no scrollbar must not retain an empty scrollbar gutter.
- When overflow exists, the reserved gutter keeps option text clear of the custom rail. Native select values remain authoritative and keyboard/mouse/touch behavior remains unchanged.

Current cache identity: app/browser-compat/release-bootstrap `v1309`, stylesheet `site.v1309.css`, cache key `1309`; the 1.3.8 JavaScript triplet is the immediate startup/cache bridge.
