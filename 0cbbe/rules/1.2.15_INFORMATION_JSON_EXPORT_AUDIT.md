# VulkanScope Database 1.2.15 Information / JSON export audit

- Immutable predecessor: VulkanScope Database 1.2.14, ZIP SHA-256 `eedc9dcabca095a0a02e041c2c46b79e8bfe3798f5a9b871c9f0efb6bc5b0d86`.
- Settings exposes four categories: Internet, Favorites, Preferences and Information. Information is local/read-only and is rendered from repository-declared metadata.
- The dependency inventory covers the first-party frontend plus the explicitly declared/referenced toolchain/runtime components: Wrangler 4.130.0 (`MIT OR Apache-2.0`), sharp 0.35.4 (`Apache-2.0` override), esbuild (`MIT`, exact transitive version not pinned), workerd (`Apache-2.0`, exact transitive version not pinned), Cloudflare D1, Web Platform APIs, Node.js standard library and Python standard library.
- Exact versions are shown only when pinned by this repository. No package-lock is shipped, so Wrangler transitive versions are deliberately represented as resolved by Wrangler 4.130.0 instead of invented numbers.
- The Pages/browser runtime continues to use first-party vanilla HTML/CSS/JS with no third-party JavaScript framework, analytics library, advertising library or remote font dependency.
- Report details add Download JSON beside Favorite, Share and Copy link. It fetches the existing `/v1/reports/:id?compact=1` representation, creates a local UTF-8 `application/json` Blob and triggers a local download. It introduces no POST request, export API, D1 mutation or report normalization/rewrite.
- Sascha Willems' Vulkan Hardware Database documents per-report Vulkan Profile JSON generation/download. That reference is used only as a UX precedent; VulkanScope's download remains explicitly its stored public report JSON and is not represented as a Khronos Vulkan Profile.
- Responsive contract: four Settings tabs are four columns on wider layouts and 2×2 at <=430 px; Information cards and license/source values wrap; four report actions wrap safely on narrow/mobile widths.
- Browser assets: `assets/app.v1215.js`, `assets/browser-compat.v1215.js`, cache key 1215.
- Mandatory gates: focused positive verifier, negative-mutation suite, immutable 1.2.14 regression contract, source and staged Pages audits, JS syntax, Worker contract, D1 migration replay and deterministic strict-package build.
