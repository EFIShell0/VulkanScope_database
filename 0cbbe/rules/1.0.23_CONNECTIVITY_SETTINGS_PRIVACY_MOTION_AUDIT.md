# VulkanScope Database 1.0.23 connectivity / Settings / interaction-motion audit

## Scope
Database 1.0.23 is a frontend interaction, browser-local preference and live-connectivity presentation release. It does not change report evidence, report identity, D1 storage, submission schema, technicalReport schema, normalizer behavior, Vulkan registry semantics or the VulkanScope producer floor.

## Live connectivity state
- Browser `online` / `offline` events are monitored immediately.
- An offline state opens a persistent top-of-page status surface that occupies layout space instead of covering Database content.
- When a connection returns, the Database immediately rechecks the live API and release marker. A successful live API response changes the status to restored; that restored state remains visible for three seconds and then collapses smoothly.
- If the browser reports online but repeated live synchronization or an explicit network-info refresh cannot reach the API, the UI reports Database API unavailability rather than claiming the physical network is disconnected.
- Existing loaded report data may remain viewable while offline; the banner explicitly states that live reports, synchronization and update checks are unavailable.

## Settings categories and local privacy state
- The Settings drawer has exactly three first-class categories: Internet, Favorites and Preferences.
- Internet contains request-scoped network observations and local clock/time-zone information. IPv4 is presented in orange and IPv6 in green; the second address family and DNS resolver remain non-fabricated when unobserved.
- Favorites remain validated report IDs only.
- Preferences contains the three report-column defaults plus `Remember on this device` and `Clear saved browser data` controls.
- Persistent Favorites/UI preferences are opt-in. Before `Remember on this device` is enabled, Favorite and column-default changes are in-memory session state only and must not be written to localStorage.
- Enabling Remember stores only the allow-listed Favorite IDs and UI defaults in browser local storage. Disabling Remember removes those persistent values while retaining the current in-memory session state. Clear saved browser data removes both persistent values and current Favorite/default state.
- The UI states that Favorites/preferences are browser-local and are not sent to VulkanScope or stored in D1.

## Report action and motion refinement
- Report-detail Favorite, Share and Copy link actions use one grouped VulkanScope-style action surface with local inline SVG icons; the old widely separated page-button layout is not used.
- Report-row hover/press backgrounds transition smoothly rather than switching abruptly.
- Opening and closing report detail uses short compositor-only opacity/transform transitions. Report data must not be delayed, modified or reinterpreted by motion.
- `prefers-reduced-motion` disables decorative transitions while preserving all navigation and actions.

## Immutable boundaries
No D1 migration, report payload/hash rewrite, schema change, normalizer bump, producer identity change, third-party script, analytics service, external IP service or fabricated network value is introduced.
