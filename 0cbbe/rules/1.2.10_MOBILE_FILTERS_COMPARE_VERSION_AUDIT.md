# VulkanScope Database 1.2.10 mobile-filter / Compare-version audit

## Scope
This release is presentation-only hardening over immutable Database 1.2.9. No report schema, D1 migration, normalizer, report identity/hash, producer floor, Vulkan registry baseline or evidence-state semantics change.

## Non-Reports mobile filter containment
- Reports keeps the 1.2.9 grouped responsive path unchanged.
- Every other primary workspace that exposes global filter families uses a single `minmax(0,1fr)` column at <=900 px. The filter host, family cards, family control grid, enhanced custom-select wrapper/button and native select fallback are all constrained with `min-width:0` and 100% maximum width.
- View-specific `.subfilters` also collapse to one intrinsic column at the same breakpoint. Compare's evidence filter row follows the same rule, so Section and Field search cannot force horizontal viewport overflow.
- The change is presentation-only; native selects remain authoritative form state, FILTER_FAMILIES/FILTER_APPLICABILITY remain the source of filter semantics, and keyboard/listbox behavior is unchanged.

## Cross-producer warning version emphasis
- The two compared VulkanScope application version identities are still escaped before insertion.
- Each version plus optional versionCode is wrapped only in `.compare-version-token`; CSS renders those tokens bold white. The warning sentence, cross-producer detection and evidence eligibility are unchanged.
