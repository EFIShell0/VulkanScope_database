# VulkanScope Database 0.34.3 API version UI

- Device API and Loader API remain separate technical fields.
- API values use a shared compact card/chip presentation with strong high-contrast text.
- The same treatment is applied to Versions, Devices Max API, Portability, report Overview and Compare where the corresponding typed field is known.
- Raw version text is unchanged. No version is inferred from another field.
- Styling is presentation-only and does not affect filtering, sorting, normalization or report state.
