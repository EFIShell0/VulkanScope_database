# VulkanScope Database 1.3.7 browser brand-mark audit

## Scope

Database 1.3.7 is a Browser information presentation-only successor to immutable Database 1.3.6 (ZIP SHA-256 `864e515dffa51d59ab9bf6b790b96a8bfea791cd782408b283df7264de8d22b8`). D1 migrations/storage, report identity/hashes, normalizer 16, Vulkan 1.4.362/header 362, submission floor and browser compatibility floors are unchanged.

## Browser mark policy

The Browser information summary now selects a local, same-origin browser mark only after browser identity can be explicitly distinguished. Current mappings cover Google Chrome, Chromium, Microsoft Edge, Firefox, Safari, Opera, Brave, Vivaldi and Samsung Browser. Generic Chromium-family results deliberately keep the neutral globe instead of borrowing a product trademark.

Marks preserve intrinsic brand colors; CSS applies no recoloring or tint filter. The mark files are package assets and are staged by the Pages allow-list. No logo CDN, favicon resolver, third-party analytics/fingerprinting service or automatic upstream logo request is used.

Samsung's current product name is presented as Samsung Browser while accepting the established `SamsungBrowser/` token. Brave detection is best-effort from browser-exposed Brave/Client-Hint signals and does not add fingerprinting probes.

## Provenance

`licenses/browser-marks.md` records the official vendor product/brand reference pages used to verify the marks and the non-affiliation/trademark notice. Brand marks remain property of their respective owners and are used only for descriptive browser identification.
