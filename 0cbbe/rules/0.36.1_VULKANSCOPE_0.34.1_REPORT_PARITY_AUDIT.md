# VulkanScope Database 0.36.2 / VulkanScope 0.34.2 Report Parity Audit

The Database Worker accepts schema 2 / technical report 3 without a hard-coded application-version ceiling, so VulkanScope 0.34.2 is accepted under the existing producer compatibility contract.

The structured consumer replaces report detailedProperties with `technicalReport.devices[].detailedProperties` when schemaVersion is 3. This makes new validated property rows, including Host Image Copy layout arrays, visible without adding extension-specific schema keys.

The report detail UI exposes Properties, Limits, Features, Formats, Memory, Queues, Surface, Display & HDR, Extensions, Instance/Layers, Profiles, Registry and Raw report. Compare also consumes detailed properties and structured category data.

Published-spec metadata was updated to Vulkan 1.4.360 (2026-08-14), matching the producer/query baseline revision while keeping runtime device API and driver versions separate.
