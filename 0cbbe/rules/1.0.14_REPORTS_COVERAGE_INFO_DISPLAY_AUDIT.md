## Requested UI/data-integrity changes
- Reports keeps the three-horizontal-line Submitted disclosure control physically pinned to the left. `Submitted` appears only to its right while expanded. Date/Time/Time zone expansion grows the table horizontally; technical columns receive explicit non-squeezing minimum widths.
- Multi-state percentage families calculate their denominator and dominance decision from every represented state, including `Unknown` and `Not applicable` where present. Every maximum state (including tied maxima) remains solid; every strictly lower peer is black-hatched. `0.0%` remains visible as an empty, state-tinted hatched track rather than disappearing.
- GitHub repository presentation gains a local Developer Info panel for `Semih Boran` / `EFI Shell`.
- Coverage-report lists open in a centered modal over a dark backdrop. The launcher uses a right arrow and retains report-detail navigation, Escape/backdrop close, focus restoration and reduced-motion behavior.
- >=80% semantic spray/glow is anchored to a clamped track endpoint rather than a fill pseudo-element, preventing the 100% endpoint from clipping the effect.
- HDR10+ uses the exact current VulkanScope application artwork (`SHA-256 8c38222517cd48357da8a93623e3c40aa06cccc7046e806b89cf81350907aba8`) as a cache-busted local asset with no CSS inversion/filter.
- Resolution and preferred wide-gamut values share the same proportional, boxed display-value typography in aggregate and report-detail views.

## GPU vendor-ID provenance audit
The VulkanScope 1.0.19 native collector serializes `VkPhysicalDeviceProperties.vendorID` (for example `properties.vendorID` / `physicalProperties.vendorID`) into the report `vendorId`. The Database Worker requires technical-report `vendorId` to equal the top-level `gpu.vendorId` and persists that submitted field to `vendor_id`. The browser now canonicalizes only `gpu.vendorId`; it no longer falls back to any textual `gpu.vendor` field. Human-readable `VENDORS` entries are presentation labels only and never synthesize the raw ID.

The presentation map retains the audited identifiers used by current reports and Vulkan/Khronos reserved IDs: Qualcomm `0x5143`, Arm `0x13B5`, Imagination `0x1010`, Huawei `0x19E5`, NVIDIA `0x10DE`, AMD `0x1002`, Intel `0x8086`, Samsung `0x144D`, Broadcom `0x14E4`, Khronos `0x10000`, Vivante `0x10001`, VeriSilicon `0x10002`, Kazan `0x10003`, Codeplay `0x10004`, Mesa `0x10005`, PoCL `0x10006`, Mobileye `0x10007`, Ape `0x10008`. Unknown IDs remain raw/Unknown rather than being guessed from the GPU name.
