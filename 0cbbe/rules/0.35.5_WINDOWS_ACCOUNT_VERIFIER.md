# VulkanScope Database 0.35.5 Windows account verifier

- Production Cloudflare account verification remains fail closed and pinned to `ccf3de9d3f2a4394af2fb7be7fd5bbf4`.
- On Windows, the verifier must not depend solely on executing `npx.cmd` directly through `execFileSync`; project-local Wrangler is invoked through the current Node executable when available.
- `wrangler whoami --json` is the preferred machine-readable identity check. Plain-text fallback is permitted only when the exact pinned account ID is present.
- Wrangler debug-log environment variables are not inherited by the verifier subprocess, preventing debug output from corrupting JSON identity parsing.
- A missing local Wrangler executable may fall back to `npx`, but a command error, unreadable identity or account mismatch blocks deployment, migration and D1 diagnostics.
- This reliability fix must not relax account isolation, alter D1/report schema semantics, or modify public capability data.
