# VulkanScope Database 0.34.5 Display/HDR audit

- Display/HDR aggregate uses the submitted Android manufacturer/model as Device identity and does not render GPU name/vendor logos.
- Vendor/GPU filters are hidden and ignored for this view so stale GPU filter state cannot silently suppress phone/device rows.
- Empty HDR type arrays are explicit Unavailable. Existing display metadata remains independently visible when reported.
- HDR artwork is local-only, presentation-only and matched only to explicit submitted type names. Unknown types retain their raw string.
- HDR logo chips use the same compact bordered-card language as API-version chips and preserve responsive layout.
