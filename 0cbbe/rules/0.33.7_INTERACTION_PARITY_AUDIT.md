# VulkanScope Database 0.33.7 interaction and parity audit

- Report-detail section changes use a short exit/enter transition. `state.detailTab` remains the single source of truth; rapid clicks are token-gated so an older animation cannot overwrite a newer selection.
- Report tabs support mouse/touch plus ArrowLeft/ArrowRight/Home/End keyboard navigation. Reduced-motion users receive immediate content changes.
- Distinct-value and report-coverage disclosure controls use native buttons with `aria-expanded`; panel height/opacity and chevrons animate symmetrically on open and close. Missing technical values are never changed by presentation state.
- Report Queue detail exposes presentation support per queue family only when the submitted Surface presentation-queue data supplies it; otherwise state is Unknown.
- Report Surface detail exposes presentation queue results and schema-v3 Surface query diagnostics when reported.
- Current Vulkan Hardware Database parity was re-checked for device report queue presentation support, memory, Surface properties/formats/present modes, and compare categories. No unsupported/available state is inferred from missing fields.
