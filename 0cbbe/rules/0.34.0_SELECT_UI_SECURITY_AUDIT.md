# VulkanScope Database 0.34.0 selection UI and regression audit

- System Vulkan driver choices in custom listboxes emphasize only the reported GPU model name; driver mode/version text keeps normal weight.
- Turnip / third-party driver choices retain the dedicated red accent treatment and are not reinterpreted as system-driver entries.
- Native `<select>` elements remain authoritative state; custom HTML is escaped before insertion.
- Selection presentation must never alter the report GPU name, driver name/mode, driver version, or comparison identity.
- Existing 1.4.360 canonical/raw Vulkan semantics, exact U64 handling, report state semantics, CSP, Worker validation and database limits remain unchanged.
- Regression checks cover frontend/Worker syntax, versioned assets, unsafe dynamic-code constructs, external-link rel attributes, schema parsing, duplicate asset references and custom-select keyboard/touch state paths.
