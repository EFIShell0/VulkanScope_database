# VulkanScope Database 0.39.1 / VulkanScope 0.41.5 Compatibility Hardening

## Finding

Database 0.39.0 accepted schema-compatible future producers, but the strict query-diagnostic and queue/Vulkan Video validators were enabled only when `application.version` was exactly `0.41.4`. VulkanScope 0.41.5 could therefore be accepted without the stricter semantics that 0.41.4 established.

## Fix

The Worker now derives the VulkanScope 0.minor.patch version and applies the 0.41.4 semantic contract to all producers at 0.41.4 or newer. VulkanScope 0.41.5/415 is the current producer identity. Historical supported versions remain accepted.

## Invariants

Submission schema 2, technicalReport 3, normalizer 15, canonical report hashing and stored D1 rows are unchanged. Non-available Vulkan Video query states require null numeric masks; current query status tokens remain allow-listed. No capability inference or migration is introduced.
