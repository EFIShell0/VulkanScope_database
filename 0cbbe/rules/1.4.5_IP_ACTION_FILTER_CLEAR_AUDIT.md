# VulkanScope Database 1.4.5 — IP action ownership / filter-search clear audit

## Scope

This release is presentation/interaction-only. It does not change report payloads, hashes, D1 schema/migrations, normalizer 16, Vulkan 1.4.362 registry evidence, or the VulkanScope 1.4.0+ new-submission floor.

## Address privacy interaction

Observed Active/IPv4/IPv6/Pseudo IPv4 rows retain independent masked/revealed state. The address container is non-interactive: only the explicit eye-labelled **Show/Hide** button owns pointer/keyboard activation and `aria-pressed`. The button updates its nearest privacy shell; the address text, mosaic and shield do not toggle state when clicked. Leaving Internet/remasking behavior from 1.4.1–1.4.3 remains unchanged.

Show/Hide uses local hover, press and focus transitions. `prefers-reduced-motion: reduce` removes decorative transitions without changing the privacy state machine.

## Search clear controls

Every enhanced searchable select/filter creates the same local X clear control used by other Database searches. It is hidden and removed from tab order while the query is empty, appears when the query becomes non-empty, and clears the entire query with one activation. Clearing resets option pagination to page 1, scrolls the option surface to its start through the existing renderer, and returns focus to the search field. Reopening a searchable selector resets the query and re-synchronizes X visibility.

The global report search, Encyclopedia search and row-filter text searches keep their existing local clear controls. Browser-native WebKit search cancel glyphs remain disabled to prevent duplicate/inconsistent clear actions.

## Release boundary

Current browser-visible assets are `app.v1405.js`, `browser-compat.v1405.js`, `release-bootstrap.v1405.js` and `site.v1405.css`, cache key 1405. The 1.4.4 JavaScript triplet is the immediate cache/deployment bridge; the 1.4.3 triplet is absent from the strict package.

Mandatory gates include the focused 1.4.5 verifier, negative mutations, immutable 1.4.4 regression verification, source/Pages audits, Worker contract, D1 migration replay and deterministic strict-package construction.
