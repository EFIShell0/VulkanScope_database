# VulkanScope Database 1.3.4 filter scrollbar / Compare chevron audit

This release is a presentation-only successor to immutable Database 1.3.3 (`8bdae138166680e64a9e6282a68d619d807f9fe8a178f799ef75ad8e90038955`). It does not change D1 schema/migrations, report payload or hash semantics, normalizer behavior, Vulkan registry/query baseline, producer floor, or validated browser floors.

Mandatory checks:

- Searchable custom-select rails are demand-driven. Merely opening a filter menu must never reveal the custom vertical scrollbar. The rail becomes visible only when `syncSurfaceScrollbar` marks it `.is-scrollable` from real `scrollHeight - clientHeight` overflow.
- Non-scrollable filter rails remain `aria-hidden`, non-interactive, visually hidden, and must not reserve a clickable gutter. Native/custom scroll behavior for genuinely overflowing option lists remains intact.
- Compare chevron semantics follow the workspace state: expanded/full header with the **Minimize** action shows an upward chevron; minimized/closed header with the **Expand** action shows a downward chevron. JavaScript path geometry remains the single direction owner; CSS must not rotate the SVG by state.
- Compare label, `aria-expanded`, title, and chevron geometry change together through `setCompareMinimizeControl`, including reset/unpin behavior.
- Existing symmetric License/filter pagination motion and `prefers-reduced-motion` behavior from 1.3.3 remain intact.
- Pages stages the immutable 1.3.3 predecessor app/browser/bootstrap triplet together with the 1.3.4 current triplet. Repository repair removes the older 1.3.2 bridge.
- Current source/Pages identity is 1.3.4 / cache 1304. The 1.3.4 verifier and negative-mutation suite run at all release gates.
- Regression contract is anchored to the immutable 1.3.3 release ZIP; deterministic clean-extract packaging and D1 migration replay must pass.
- No D1 migration is required for 1.3.4.
