# VulkanScope Database 0.35.3 coverage background containment

The global semantic status classes also carry background colors. Coverage widgets reuse the same status class to color their progress fill, so non-dominant coverage containers could accidentally inherit the full status background even though 0.35.1 intended only their fill to remain colored.

0.35.3 explicitly neutralizes the coverage-container background for every non-dominant state while leaving the progress fill semantic. The unique dominant state retains the broader semantic emphasis. Count badges are unaffected.
