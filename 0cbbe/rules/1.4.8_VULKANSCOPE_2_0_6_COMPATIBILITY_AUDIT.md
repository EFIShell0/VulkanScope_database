# VulkanScope Database 1.4.8 — VulkanScope 2.0.6 compatibility audit

Database 1.4.8 succeeds immutable Database 1.4.7 (ZIP SHA-256 `72464d6e0aa9fb1518cd045281428458cd480fafa7c5333b22643f619a781fcb`). This release updates the new-submission contract to the VulkanScope 2.0.6 report envelope and Vulkan 1.4.364 registry baseline without rewriting historical D1 payloads, report hashes, canonical IDs or normalizer 16 data.

## New-report producer floor
- New `POST /v1/reports` submissions require VulkanScope **2.0.6 or newer**. VulkanScope 2.0.6 is accepted at the floor; 2.0.5 and every lower producer are rejected before generic report validation.
- The 2.x semantic-version/versionCode identity is fail-closed: `versionCode = 2000 + minor*100 + patch`. Unknown major-version identity schemes remain rejected until explicitly audited.
- The floor applies only to new submissions. Historical stored reports below 2.0.6 remain readable through existing GET/list/Compare paths and are not deleted, migrated, normalized again or rehashed.

## VulkanScope 2.0.6 report compatibility
- The top-level envelope remains schema 2 and the technical report remains schema 3. No D1 migration or normalizer increment is introduced.
- The exact current `device` envelope includes `platform`, `chromeOsArcRuntime`, `androidPcFormFactor`, `freeformWindowManagement`, `googlebookEnvironmentEvidence`, `googlebookOsVersion`, `hostOsVersion`, manufacturer/brand/model/device/product, Android release/SDK and security patch.
- Googlebook/Android-PC/ChromeOS evidence is stored exactly as reported by VulkanScope. Database validation does not infer host ChromeOS identity or version from model, brand, fingerprint or other heuristics.
- The submission transport ceiling remains 2 MiB and all existing complete-report, sensitive-key, UTF-8, canonical-hash and bounded-resource checks remain mandatory.

## Vulkan registry / Encyclopedia baseline
- Current registry/spec baseline is Vulkan **1.4.364**, published 2026-09-25. The bundled `registry/upstream/vk.xml` SHA-256 is `4cfe3c137f3a95c15275b1cfda0aee407dbf131de2005a3552aa41c49f895c89`.
- Vulkan-Headers remains pinned to tag `v1.4.364`, commit `b0c3dd6851e22621f194306d511b9253e4c1577f`, `VK_HEADER_VERSION 364`.
- Registry census is 477 registered Vulkan extensions. `VK_INTEL_device_info` and `VkPhysicalDeviceInfoPropertiesINTEL` are release sentinels for the 1.4.364 update.
- Generated Encyclopedia census is commands 842, tokens 6257, types 2462, extensions 477 and VkResult entries 50. Registry presence remains reference information only and never implies runtime support.

- Database/frontend/Worker source identity is 1.4.8 with current browser assets `app.v1408.js`, `browser-compat.v1408.js`, `release-bootstrap.v1408.js`, `site.v1408.css` and cache key 1408. The v1407 JavaScript triplet is retained as the immediate cache-propagation bridge.
