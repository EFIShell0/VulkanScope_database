# VulkanScope Database 1.2.14 — Page jump / Browser information audit

## Scope
- Adds direct page-number navigation to every user-visible pagination surface without changing sort/filter/report semantics.
- Adds a local-only Browser information section below My internet information in Settings > Internet.
- Keeps VulkanScope 1.2.13 as the immutable predecessor and preserves schema 2 / technical report 3, normalizer 16, Vulkan 1.4.362/header 362, D1 migrations, report hashes and the VulkanScope 1.2.5 submission floor.

## Direct page jump
- Searchable filter listboxes, Reports, bounded aggregate tables and paged evidence/value modals all expose the same compact page-jump primitive.
- The page field accepts decimal digits only. Empty editing is temporary; non-empty input is valid only in the inclusive range 1..current page count.
- Out-of-range values cannot be inserted by keyboard, paste or other input events. Enter and the Go button commit a valid page. Escape restores the active page. Arrow Up/Down move one valid page.
- Search result count and page-size changes immediately update the allowed maximum and field length; a filter search still resets to page 1.
- Mobile and desktop layouts must remain contained without document-level horizontal overflow. Existing 50-option filter pages and 50-row maximum tables/modals remain unchanged.

## Browser information
- Settings > Internet contains a separate Browser information card after My internet information.
- Browser/runtime values are read locally from standard browser APIs. They are never attached to reports, submitted to the Worker, or stored in D1.
- The section may show best-effort browser name/version, rendering engine, compatibility family, user agent/client hints, platform/languages, privacy signals, CPU/memory/touch exposure, viewport/screen data, preferences and selected Web Platform capability availability.
- Missing or privacy-restricted values are shown as Not exposed/Unavailable rather than inferred.
- No GPU renderer fingerprint, canvas fingerprint, remote browser-identification service, third-party script or tracking request is permitted.
