# VulkanScope Database 1.4.10 Profiles / loader / Submitted-time audit

## Scope
This release is a presentation and startup-correctness successor to immutable Database 1.4.9. It does not change D1 schema, normalizer 16, stored report bytes/hashes, report IDs, Vulkan 1.4.364 evidence semantics or the VulkanScope 2.0.6+ new-submission floor.

## Profile readability
The structured `profileEvaluation` payload remains losslessly preserved. The report Profiles renderer retains evaluator totals, per-family breakdowns, evaluator context and failing/unknown evidence while increasing the previously undersized copy for desktop and mobile.

## Single-stage startup loader
The startup surface uses the bundled horizontal VulkanScope logo, a rotating circular indicator and the existing progress bar. Its fixed panel is overflow-hidden, so it cannot expose an internal native scrollbar or arrow chrome. Page Up/Down controls, the fixed viewport rail and page progress are fail-closed while `body.database-loading` is active. The versioned release bootstrap keeps the `release-check-pending` visibility gate so the predecessor UI is not painted during the ready-release check/cache-busting handoff.

## Submitted seasonal-time disclosure
The Reports table derives every displayed time value from the server-authored `submitted_at` instant. Expanded Submitted rows expose Standard/winter offset, Daylight/summer offset, yearly seasonal-change presence and the offset state at submission. Fixed-offset zones explicitly report that no seasonal clock change is observed. No timestamp or stored evidence is modified.

## Collapse animation
The Submitted column uses a measured JavaScript width transition that writes temporary inline-important width/min-width/max-width values frame-by-frame, then removes them at completion so the class-owned final size wins. This avoids the historical `!important` table-width rules causing a snap on close. The inner reveal keeps its CSS width/max-height/opacity transition. Reduced-motion skips the measured width animation.

## Release boundary
Current assets are v1410; only the v1409 app/browser/release-bootstrap triplet is retained as the one-release cache bridge. v1408 JavaScript is stale and forbidden in the strict release package. The static preload + authoritative live index + `/v1/sync` delta model is unchanged from 1.4.9.
