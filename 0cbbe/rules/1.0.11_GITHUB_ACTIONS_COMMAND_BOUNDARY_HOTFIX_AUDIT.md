## Reproduced failure
The 1.0.10 Pages workflow wrote `Reverify generated index metadata` with a one-line `run:` scalar followed by another indented Python command. YAML folded the continuation into the same shell command, so `python tools/test_1_0_10_reports_render_hotfix_negative_mutations.py` was passed as unexpected arguments to the verifier. GitHub Actions therefore failed with exit code 2 before staging/deployment.

## Repair
- Both canonical and deployed workflow copies use `run: |` for the multi-command reverify step.
- The current verifier and negative-mutation test execute on separate lines and therefore as separate shell commands.
- A dedicated verifier checks the exact command boundary and workflow-template byte equality.
- A negative mutation restores the malformed 1.0.10 scalar in both workflow copies and requires rejection for the command-boundary reason.
- The 1.0.10 Reports row-array fix and all 1.0.9 live/UI/floor behavior remain directly verified.
