# VulkanScope Database 0.34.7 audit

- Display/HDR hides vendor, GPU-model and Vulkan API-version selectors.
- `filteredReports()` explicitly ignores all three values while `state.view === "display"`, so stale hidden selections cannot suppress device/HDR rows.
- Status filtering remains available because Display/HDR has meaningful Available/Unavailable state.
- No Vulkan data, HDR mapping, Worker route, security policy or schema semantics changed in this release.
