# VulkanScope Database 0.37.0 Trends and Permalink Audit

Database 0.37.0 updates the current producer identity to VulkanScope 0.41.0 / versionCode 410 while preserving schema 2 / technicalReport 3 and the existing D1 corpus.

The frontend adds loaded-submission trend summaries and report/compare permalinks. Trend percentages are explicitly not market share. Extension aggregation counts exact runtime-enumerated tokens only and does not infer Unsupported from absence.

Report ids are accepted for routing only when they are lowercase 64-hex values present in the loaded report set. Detail tab names are allow-listed and compare routes require two valid loaded ids.

Worker D1 access remains parameter-bound, POST reads remain 2 MiB streaming bounded, CORS stays pinned to the configured production origin, and current producer versionCode mismatches fail closed.

Cloudflare observability is enabled with sampled logs/traces. The Worker does not add custom payload logging.

No D1 migration, payload rewrite, report hash rewrite or capability-state normalization change is introduced by this release.

Wrangler is pinned to 4.125.0 for this release.
