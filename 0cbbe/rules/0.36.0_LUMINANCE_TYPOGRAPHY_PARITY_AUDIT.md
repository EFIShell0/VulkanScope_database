# VulkanScope Database 0.36.0 — Luminance Typography Parity Audit

## Scope

Display & HDR luminance presentation was compared against OpenGLESScope Database 0.2.0.

## Result

- Numeric luminance remains the primary text.
- `cd/m²` uses a dedicated muted unit span with `font-size: .92em`.
- Existing `cd/m2`, `cd/m^2`, and `cd/m²` forms normalize only at presentation time.
- Aggregate and report-detail Display & HDR views share the same markup.
- No stored report data, capability state, schema, Worker normalization, or D1 rows are rewritten.
