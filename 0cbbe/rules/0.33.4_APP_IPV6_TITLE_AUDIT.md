# 0.33.4 application, title, IPv6 and protocol audit

- VulkanScope 0.32.4 schema-v3 structured report data is preferred for features, detailed properties, limits, profiles, memory, queues, formats, surface and registry coverage.
- Vulkan registry/query baseline is Vulkan 1.4.360.
- Browser titles are synchronized with active main/detail navigation.
- The Worker stores no request IP and performs no IPv4-only parsing. Cloudflare transport may deliver IPv4 or IPv6 clients without affecting report schema or identifiers.
- Exact U64 decimal strings emitted by VulkanScope are used where available, avoiding JavaScript Number precision loss.
- CSP remains local-only except the configured HTTPS Worker endpoint.
