# Security and data policy

The public database must contain technical Vulkan capability information only.

Do not publish IMEI, Android ID, device serial numbers, MAC addresses, user/account identifiers, private file paths, authentication tokens or IP addresses as report fields.

The site has no third-party JavaScript, analytics, remote fonts or advertising dependencies. Its Content Security Policy permits only same-origin resources and data images.

Database submissions are repository changes and therefore reviewable before publication. Unknown, unsupported and unavailable capability states must remain distinct.
